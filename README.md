# Client Screening

## Repository Purpose

This repository contains the technical design and implementation artifacts for a scalable movie 
ticket booking system, and it also contains the written and audio responses to the interview questions.

## Repository Structure

### Audio Answer
    Contains the audio recordings of the question "What does a well-run software engineering team look like to you?"

###  tech-skills
    Contains the system design documentation, database design, booking workflow, technical challenges,
    and architecture diagrams.
   * database-design.md
   * booking-workflow.md
   * system-design.md
   * project-overview.md

  ##  diagrams
     Contains architecture diagrams illustrating the system components, request flow, and interactions.

### Written Responses
    Contains the written responses to the interview questions, including experiences, challenges, and learnings.
